# Architecture Decision Records

`ADR-000-living-document.md` is special: it's a persistent backlog and
sketchpad, meant to be edited across sessions rather than frozen once
written. Read it first.

Every other `ADR-NNN-*.md` file records one decision made at one point in
time (context, decision, consequences) and stays as-is afterward, aside
from status updates (e.g. marking one superseded by a later ADR).
